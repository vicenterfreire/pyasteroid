# Neon Asteroids

A modern, neon-styled Asteroids clone built with Python, Pygame, and NumPy.

## Features

- Procedural neon graphics with glow effects
- Particle system for explosions and thrusters
- Procedural sound generation with NumPy
- Progressive difficulty with waves
- UFO enemies with AI
- High score persistence
- Customizable background

## Installation

1. Clone or download the project
2. Install dependencies:

```bash
pip install -r requirements.txt
```
